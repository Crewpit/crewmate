Crewmate

Install Cockpit apps from the Crewpit registry, a git URL or an archive, keep them up to date, and remove them when you're done.

Installed Packages

Packages Crewmate installed, plus any other Cockpit package on this machine that has a preflight.json (looked up in /usr/share/cockpit and /usr/local/share/cockpit). Cockpit's bundled packages are left out.

Crewpit Registry

Source:

From a Git URL

Any git URL (GitHub, GitLab, Gitea or self-hosted), or a direct http(s) link to a .tar.gz or .zip file.

Used as the folder name under /usr/share/cockpit/.

Upload a ZIP

A .zip or .tar.gz of a Cockpit package. If everything sits inside one top-level folder, that folder is stripped.

Debug Log

Each command Crewmate runs and everything it prints, in order. The log lives in memory and is cleared when you leave the page.
